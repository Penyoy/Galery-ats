# GALERY ATS
 galery Ats dibuat untuk memudahkan dan memperindah tampilan galery di dalam smartphone atau hp, dengan tujuan awal untuk menggantikan galery sistem yang cenderung statis dan cenderung membosankan dengan fitur minim

## Feature
> unggulan yaitu PIP (picture in picture)
> PIP tidak hanya untuk video tetapi bisa juga untuk foto
> memiliki 3 efek animasi : fade, zoom dan cascade
> meregang ketika dipaksa tarik ketika sudah mentok
> pilihan ukuran thumbnail: persegi, potret dan asli
> penambahan fitur favorite
> memiliki tema terang dan gelap
